# Change: 网页上传图片到存储卡并实时更新相册

## Why
现有网页只能设置轮播方式，向设备添加图片仍需手动拷贝和触发媒体扫描。增加网页上传后，可从电脑或手机直接传入图片，让运行中的相册自动发现新内容。

## What Changes
- 在现有 `http://设备IP:8000/` 页面增加图片上传区域，支持选择单个文件、多个文件，或选择文件夹后递归上传其中支持的图片。
- 网页显示实际保存目录、文件队列、上传进度和逐项结果；文件夹选择不可用的浏览器仍可多选文件。
- 自动选择已挂载的可写存储卡，使用公开图片目录 `Pictures/GalleryUploads/`；当前设备预计落到 `/storage/EE06-1B08/Pictures/GalleryUploads/`，由实际存储卷解析决定，不硬编码卷 ID。
- 没有可写存储卡时明确提示，不静默改存到内置存储。多个存储卡时按稳定规则选定一个，并显示目标。
- 首期支持 JPEG、PNG、WebP、GIF、BMP 图片，单文件上限 50 MiB；服务端验证实际图片内容。文件夹中其他文件跳过并计数，全部图片统一保存到目标目录，不保留本机子目录结构。
- 同名图片自动另存新文件，保留原图；中断或失败不留下可播放的半成品。
- 图片写入完成后立即发布媒体索引，再通知播放页面更新媒体列表和单图缓存；批量上传时合并刷新，不依赖重启、手动扫描或整个轮播间隔结束。
- 延续现有自动开启、固定 8000 端口和无需访问口令的行为。

## Impact
- Affected specs: 新增 `web-image-upload`；现有 `add-web-settings` 行为保留。
- Affected code: `settings.html`、`WebSettingsServer.java`、`WebSettingsController.java`、`FirstFragment.java`，以及新增图片写入和媒体发布组件及相关测试。
- 需要将 HTTP 请求体处理从仅有的小 JSON 扩展为限流式文件写入，并允许上传期间其他设置请求正常完成。
- 当前设备只读检查结果：Android 11（API 30），可移除公共卷 `EE06-1B08` 已挂载。写入能力及媒体索引将在实施时通过应用自身验证。
