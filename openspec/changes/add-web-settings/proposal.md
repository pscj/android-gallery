# Change: 通过网页配置图库设置

## Why
目前只能在 Android 设备上长按打开设置，不便于操作壁挂屏或数字标牌。提供网页入口后，用户可在浏览器输入设备网址，读取和修改现有设置。

## What Changes
- 按用户已确认的同一 Wi-Fi／局域网访问设计，Android 应用提供内置 HTTP 设置页，无需独立部署网站。
- 在原设置对话框中增加网页设置开关、实际可用网址；应用启动时默认开启，显示地址，例如 `http://192.168.1.100:8000/`（以设备实际地址为准）。
- 网页提供现有全部设置：九档图片更换间隔，以及四分屏／单图模式，适配手机和电脑浏览器。
- 网页与本机共用设置存储和校验，保存后在播放界面生效，应用重启后保留；统一当前代码中 5 分钟与 10 分钟不一致的默认值为设置对话框使用的 5 分钟。
- 按用户要求去掉访问口令，打开网页自动读取设置，可直接保存；关闭网页设置时立即停止访问。
- 本期服务随应用界面存续，应用退出或进程终止后不可访问；不新增后台常驻服务。

## Impact
- Affected specs: `web-settings`（新增）。
- Affected code: `SettingsDialog.java`、`dialog_settings.xml`、`FirstFragment.java`、`MainActivity.java`，以及新增设置存储、内置 HTTP 服务和网页静态资源。
- 保留原设置入口和已有偏好键，无需迁移已保存的有效设置。
- 不涉及公网部署、域名、路由器端口映射或云端管理。
