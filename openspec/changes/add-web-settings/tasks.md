## 使用方式
1. 在 Android 设备上运行新版应用，长按播放界面打开原设置页。
2. 网页设置默认随应用启动，无需手动开启；查看显示的实际网址。开关立即生效，不需要点击保存。
3. 手机或电脑连接相同局域网，在浏览器输入显示的网址，无需口令即可设置。
4. 修改图片更换间隔或显示模式并保存；本机与网页共用偏好存储和播放更新路径。
5. 保持图库应用运行。关闭开关或销毁应用 Activity 后服务停止；每次应用启动时默认开启服务。
